# Skills

This directory is reserved for local skill packs and copied workflow references.

For now, Upstage relies on:

- `AGENTS.md` for repo-level operating guidance
- `.agents/references.md` for canonical docs and workflow entry points
- `README.md`, `mise.toml`, and `compose.yaml` for local development and infrastructure behavior

If we later vendor local skills from sibling projects, add them here and update `.agents/references.md` to point at them explicitly.
