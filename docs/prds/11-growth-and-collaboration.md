# Growth And Collaboration

## Goal

Lay the groundwork for Upstage to become sticky for teams and shareable in real sales and design workflows.

## MVP scope

- Lightweight collaboration-ready data model
- Referral or invite hooks for future growth loops
- Placeholder sharing and team access concepts
- Export surfaces that can support future client review

## Requirements

- The schema should not block future multi-user project access.
- Growth hooks should be measurable once enabled.
- Collaboration should remain optional for solo users.

## Task breakdown

- Add collaborator-ready schema ownership for projects.
- Define invite, share, and review concepts in the product model.
- Reserve analytics events for referrals, invites, and shared project views.
- Scope future permissions for editor and viewer roles.
- Document how collaboration changes billing and storage assumptions.

## Acceptance criteria

- Project ownership and collaborator relationships are modeled cleanly.
- Future team access can be added without replacing the project schema.
- Growth events have named placeholders in the event taxonomy.

## Non-goals

- Full real-time multiplayer editing
- White-label agency portals in v1
